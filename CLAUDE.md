# Conveyer — project instructions

## Python development: REPL-driven, always

For **any** Python work in this repo — writing, modifying, or debugging code —
use the `skills/repl-driven-python` skill (read `skills/repl-driven-python/SKILL.md`
before writing the first line of Python).

The non-negotiable rule it enforces: **write each function, validate it in the
live REPL (persistent Jupyter kernel, via `skills/repl-driven-python/repl_client.py`)
against real inputs and edge cases, and only then integrate it into the module
file.** Never write an unvalidated function directly into a file, and never use
"re-run the whole script" as the feedback loop.

## Data architecture

For design, modeling, and pipeline-architecture questions, use the
`skills/rich-data-architect` skill.
